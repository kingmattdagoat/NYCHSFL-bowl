# NYCHSFL Bowl

A standalone, responsive arcade-football website.

## Run it
Open `index.html` in a browser. No server or installation is required.

## Publish it
Upload the folder to any static hosting service such as GitHub Pages, Netlify, or Vercel.

## Note
This is an original arcade-football implementation inspired by the genre. It does not include Retro Bowl's copyrighted code, artwork, or branding. Player/team information should be verified against current public school rosters before public release.
